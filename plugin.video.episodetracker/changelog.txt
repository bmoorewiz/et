v1.0.1
- Added a built-in update checker. The add-on checks GitHub for a newer
  version on a configurable interval, shows an "Update available" entry on
  the main menu, and installs the new zip after you confirm.
- Update source (repository / branch) is configurable in Settings > Updates,
  with an optional access token for private repositories.
- Downloaded update zips are validated before extraction (rejects archives
  containing absolute paths, directory traversal, or out-of-tree files).
- Localized strings now format defensively so a missing translation cannot
  raise mid-operation.

v1.0.0
- Initial release.
- Trakt.tv device authentication.
- Real-Debrid device authentication.
- "Next Episodes" list built from your Trakt watched progress (only aired, unwatched episodes).
- Source scraping through the script.module.cocoscrapers module.
- Real-Debrid cached-magnet resolution and playback.
- Automatic Trakt scrobble / mark-as-watched on playback.
- Refresh and clear-cache tools.
