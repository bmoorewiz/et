v1.0.6
- Fixed "Could not resolve a playable link" on every source. Real-Debrid
  only fills in a torrent's download links once its status reaches
  "downloaded", but the add-on read the status once, immediately after
  adding the magnet, and gave up when links were absent. A new magnet is
  always still converting at that point, so this failed even for cached
  torrents. The status is now polled until the torrent is ready, with a
  configurable timeout (Settings > Playback).
- Playback failures now explain themselves instead of showing a generic
  message: not cached, dead torrent, magnet unreadable, flagged as a
  virus, no video file in the torrent, no file matching the episode, or
  the unrestrict failing.
- If a source fails, the next ranked source is tried automatically (up to
  4 by default, configurable, and can be turned off).
- Sources can be checked against the Real-Debrid cache before listing and
  are flagged and sorted accordingly. Real-Debrid has deprecated that
  endpoint, so when it returns nothing usable all sources are listed
  unflagged rather than being wrongly hidden.

v1.0.5
- Fixed scraping always finding no sources. Trakt returns year, tvdb and
  tmdb as numbers, and these were passed to CocoScrapers unchanged. The
  scrapers feed them to string operations - check_title() runs
  title.replace(year, '') - so the check failed for every candidate and
  every release was discarded. All scraper-facing values are now strings.
- Empty scrape results are no longer cached. One failed scrape used to
  hide sources for the whole cache window (6 hours by default), so a
  transient failure looked permanent.
- "No providers enabled in CocoScrapers" is now reported distinctly, with
  an offer to open its settings, instead of looking like "no sources
  found".

v1.0.4
- Trakt application credentials are now included, so signing in needs no
  setup at all: choose Authorize Trakt, then enter the code shown at
  trakt.tv/activate.

v1.0.3
- Trakt sign-in is the trakt.tv/activate device flow, the same as
  Real-Debrid: the add-on shows a code and you enter it on the website.
  Application credentials are now baked into the build rather than being
  per-install settings, so there is nothing to configure. The Settings
  fields remain as an override.
- Clearer prompt when a build carries no Trakt credentials, offering to
  open Settings instead of showing a hardcoded English message.

v1.0.2
- Fixed the source/update cache silently doing nothing when the add-on
  profile directory did not exist yet. The cache now creates it on demand.
  Previously this could leave the "Update available" entry permanently
  hidden even when a new version had been found.

v1.0.1
- Added a built-in update checker. The add-on checks GitHub for a newer
  version on a configurable interval, shows an "Update available" entry on
  the main menu, and installs the new zip after you confirm.
- Update source (repository / branch) is configurable in Settings > Updates,
  with an optional access token for private repositories.
- Downloaded update zips are validated before extraction (rejects archives
  containing absolute paths, directory traversal, or out-of-tree files).
- Localized strings now format defensively so a missing translation cannot
  raise mid-operation.

v1.0.0
- Initial release.
- Trakt.tv device authentication.
- Real-Debrid device authentication.
- "Next Episodes" list built from your Trakt watched progress (only aired, unwatched episodes).
- Source scraping through the script.module.cocoscrapers module.
- Real-Debrid cached-magnet resolution and playback.
- Automatic Trakt scrobble / mark-as-watched on playback.
- Refresh and clear-cache tools.
